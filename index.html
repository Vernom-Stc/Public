Installez Kerckhoffs sur votre téléphone

Ouvrez cette page dans votre navigateur (pas depuis une autre application), puis menu ⋮ → « Ajouter à l'écran d'accueil ». Ouvrez ensuite toujours Kerckhoffs par son icône : il se met à jour tout seul, et votre travail ne se perd pas quand vous passez d'une application à l'autre.

Kerckhoffs n'existe sur aucun store : sa seule adresse est celle de cette page.

Préparation du mode hors ligne…

Kerckhoffs ne se connecte jamais à internet. Faites le test : activez le mode avion, puis utilisez l'application normalement.

    Les deux adresses doivent être identiques, et le numéro de référence doit être le même que celui publié pour cette version, à l'adresse officielle. Chaque version officielle est signée par l'auteur de Kerckhoffs.

    Votre version ne change jamais toute seule. Celle que vous vérifiez maintenant reste exactement la même, avec ou sans internet, tant que vous ne l'effacez pas. Si une nouvelle version existe, Kerckhoffs vous le dit, c'est tout : c'est vous qui allez la chercher, quand vous voulez. Elle est alors vérifiée avant de vous être proposée, et refusée si elle n'est pas signée.

    Vérifier un message de l'auteur

    Toute communication officielle de l'auteur est signée avec son sceau. Collez ici le message entier, de « DÉBUT » à « FIN » : Kerckhoffs vérifie, sans internet, qu'il vient bien de l'auteur et qu'aucun mot n'a été changé.

    Une fausse copie pourrait afficher ce même écran, avec un faux lien. Le plus sûr reste de connaître l'adresse officielle par un autre moyen : un favori, ou quelqu'un de confiance. Pour les usages sensibles, il existe aussi un fichier signé qui ne se met jamais à jour tout seul.
