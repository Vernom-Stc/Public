Kerckhoffs

Masquez vos données avant de travailler avec une IA.

Kerckhoffs repère les noms et les numéros tout seul. Vous relisez, vous complétez au doigt, puis vous envoyez. Sur un ordinateur, vous pouvez aussi glisser un fichier sur cette page.

Installez Kerckhoffs

Sur un téléphone : menu ⋮ du navigateur → « Ajouter à l'écran d'accueil ». Sur un ordinateur (Chrome ou Edge) : l'icône d'installation dans la barre d'adresse. Ouvrez ensuite toujours Kerckhoffs par son icône.

Sécurité et versions

Préparation du mode hors ligne…

Kerckhoffs ne se connecte jamais à internet. Faites le test : activez le mode avion, puis utilisez l'application normalement.

Votre version ne change jamais toute seule. Une nouvelle version n'est installée que si vous allez la chercher, et seulement si elle est signée par l'auteur.

Kerckhoffs n'existe sur aucun store : sa seule adresse est celle de cette page. Ouvrez-la dans votre navigateur, pas depuis une autre application.

    Vérifier un message de l'auteur

    Toute communication officielle de l'auteur est signée avec son sceau. Collez ici le message entier, de « DÉBUT » à « FIN » : Kerckhoffs vérifie, sans internet, qu'il vient bien de l'auteur et qu'aucun mot n'a été changé.

    Une fausse copie pourrait afficher ce même écran, avec un faux lien. Le plus sûr reste de connaître l'adresse officielle par un autre moyen : un favori, ou quelqu'un de confiance. Pour les usages sensibles, il existe aussi un fichier signé qui ne se met jamais à jour tout seul.
